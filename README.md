# Number Guessing Game

A Flutter-based Number Guessing Game.

## Features
- Main Screen
- Game Screen
- History Screen
- Random Number Guessing
- Check Guess Result
- Restart Game
- Save Game History Locally

## Technologies Used
- Flutter
- Dart
- Shared Preferences

## How to Run
1. Open the project in VS Code.
2. Run `flutter pub get`.
3. Run `flutter run`.
